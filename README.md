# 手机之问（TapCounter）

> 每天你到底点了多少次手机？

一款通过无障碍服务统计手机点击 / 滑动 / 碰屏次数的本地安卓应用。不联网、不上传，所有数据只保存在你自己的手机里。

原项目名「点击计数」，从 v2.0 起正式更名 **手机之问**，包名保持 `com.tapcounter.app` 不变。

![手机之问图标](docs/icon_heart_nobeam.png)

## 功能

- **三口径独立统计**：点击、滑动、碰屏分开计数；碰屏 = 点击与滑动之和。
- **四套主题**：商务藏青 / Hello Kitty / 原神 / 小马宝莉，每套含官方插画背景与本色点击涟漪。
- **今日 App 排行**：看看今天哪些 App 让你点得最多。
- **亮屏统计**：亮屏次数与屏幕使用时长。
- **早报通知**：每日 8:00 推送前一天统计摘要。
- **手动分段**：手动开启 / 保存统计段，方便对比不同时段。
- **30 天记录**：查看近 30 天每日数据。

## 安装

下载 `apk/` 目录下最新版本 APK，传到安卓手机安装即可（需要允许「无障碍服务」权限，应用才能统计）。

## 技术栈

- Kotlin + Android（minSdk 24 / targetSdk 35）
- 无障碍服务（AccessibilityService）监听全局点击与滑动
- SQLite 本地存储
- Material Design 组件

## 构建

需要 JDK 17 与 Android SDK：

```bash
./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

## 目录结构

```
├── app/                 # Android 应用模块（Kotlin 源码 + 资源）
```
